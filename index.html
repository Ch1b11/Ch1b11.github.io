About

Mobile developer focused on maintainable architecture, offline-first systems, and practical engineering.

I'm a mobile developer focused on building maintainable apps with Clean Architecture, BLoC/Cubit, and practical mobile engineering. I prioritize what happens when the network drops: offline-first outbox synchronization, deterministic error handling, and robust state transitions that keep local and remote data consistent.

My flagship project is GraphSphere, an AI knowledge management mobile client designed to consume a Nest.js REST API. I built the complete Flutter client using Feature-First Clean Architecture within an Nx monorepo. It features an AI chat assistant that streams responses over SSE, offline-first sync with Hive draft autosave, an interactive force-directed knowledge graph on canvas, a Markdown editor with live syntax highlighting, and adaptive layouts across mobile, tablet, and desktop.

Across my projects, I focus on solving real mobile engineering challenges — from offline sync engines to single-flight JWT token refresh flows. I am actively looking for full-time Flutter/mobile developer opportunities where I can contribute to production-grade mobile codebases.
